Compact Assistant — AUG-196

A usable assistant inside Compact Mode: see the newest copilot hint and act on it (Open route, Ask, Dismiss), and ask the Claude session a question with the streamed answer shown, without leaving the compact widget. Three options per transcript widget; pick one per variant. Every frame is live: use Ask, type a question and press Enter, dismiss a hint.

Variant
Hint state

Variant A — Dock

The Dock follows the app theme. Every Dock Strip is 340 × 600 on a mock desktop. Clicking a hint state button again replays the “new hint arrived” event (A2 tab flash, B3 card). Dock Square is shared by all three.

Variant B — Ghost

Ghost widgets are translucent and always dark, over a dim fake video call. Every Ghost Caption is 760 wide, docked bottom. The tools row is shown permanently here (hover-only in the product); hover the caption to see the left-column tool grid. Ghost Coin is shared by all three.

Decision

Pick one Dock option (A1/A2/A3) and one Ghost option (B1/B2/B3).

RECOMMENDED A1 — keeps the transcript visible and reuses the action-items block pattern.

RECOMMENDED B3 — keeps the caption at its size and click-through behaviour.

The pick buttons only highlight; the real decision is taken in chat. No model names, prices or token counts appear in any compact widget.
