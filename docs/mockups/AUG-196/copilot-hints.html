In the product the transcript is never marked; the hint just appears. The underline and the trigger tag above exist only in this mockup, to show which phrase fired the hint.

“Searching” appears only when a hint goes to Claude; in Local hints the same state is shown as Found at once (local search takes under 0.3 s, there is nothing to wait for). Nothing found never creates a card — only the silent counter grows. Explanation unavailable has two texts: “Shown without explanation — Claude is off for this meeting.” (shown here) and, when the mode is Claude explains but Claude Code is missing, “Shown without explanation — Claude Code is not available.”

Decision

Decided 2026-11-05: four-position switch, default Off, Claude explains recommended; model Haiku / Sonnet / Opus, default Sonnet, changeable during the meeting; choosing a Claude mode is the consent.

Considered

1 · One mode with on/off

Pros

  • Simplest: one switch, one code path
  • Less settings text to read

Cons

  • No private option: every hint goes through Anthropic
  • No Always-on Claude for users who want the best catch rate

2 · Four-position switch RECOMMENDED

Pros

  • Private option (Local hints) for privacy-first users
  • Always-on Claude for quality-first users, at their own cost and after a warning

Cons

  • More settings text to read
  • Two extra code paths (local and always-on)
