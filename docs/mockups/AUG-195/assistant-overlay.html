AUG-195 — ASSISTANT and COPILOT columns: Active project session

Every state of the Active project session during a live recording: side-by-side Action items / Copilot / Assistant columns, project tabs, chat with Claude Code bound to a Praxis project, action items and Praxis tasks from a message, errors, and the separate Copilot and Assistant windows in Compact Mode.

State
Layout

Live recording

Live: collapse (–) a column to a rail and click the rail to expand; hide (×) and bring back from the pin bar toggles or Ctrl/Cmd+3 (ASSISTANT) and Ctrl/Cmd+4 (COPILOT); drag a column’s left edge to resize (240–560 px, the transcript keeps 360 px; double-click resets); the CTX badge shows COPILOT; copilot mode and model selects; tabs and the project picker; hint Ask (fills the ASSISTANT input); → Action item; → Praxis task (Creating… for 1 s, then a “Created task AUG-200” chip; created directly in the PraxisOS-off, spending-limit and crash states); Send; Stop; Stop session. Switching a state resets the chat to that state’s starting point.

Compact Mode windows

Rules

  • Full window: Transcript, Action items, Copilot and Assistant are side-by-side columns; nothing is drawn over the transcript or the action items.
  • Each column can be collapsed to a rail, hidden and shown again from the pin bar, and resized by its left edge during the meeting; the layout is remembered.
  • One tab per Praxis project in ASSISTANT; a tab is one Claude Code session bound to that project folder. Copilot follows the active tab. Closing a tab stops its session.
  • Claude starts on the first question in a tab; hints for the project start as soon as the tab opens.
  • Each question carries the last N minutes of the transcript (Settings → Transcript window); nothing is sent between questions.
  • At most 3 Claude sessions run at once (chat and copilot together); the least recently used idle one is stopped first. A session stops after 10 minutes without questions and at End Meeting; the next question resumes the conversation.
  • → Action item adds the message to Action items with an AI tag; near-duplicates are not added twice. → Praxis task asks Claude to create the task through PraxisOS; when PraxisOS or Claude is unavailable it is created directly, like Send to Praxis.
  • The panel shows no money, models (except the copilot model select), tokens or tool names; spending appears only as “Spending limit reached”.
  • Compact Mode: Dock Strip / Ghost Caption, Copilot and Assistant are separate windows, each movable and resizable; they never overlap.

Decisions (2026-11-06)

  • Columns side by side instead of the overlay; each column collapsible, hideable and resizable during the meeting.
  • Compact: Copilot and Assistant are separate movable, resizable windows that never overlap.
  • No money in the panel; only “Spending limit reached”.
  • → Praxis task: Claude creates it through PraxisOS; direct creation is the fallback.
  • Chat model is chosen in Settings only.
