Settings → General → Confirmations already has 'Skip Clear Confirmation' (SettingsModal.tsx:796-806), but no code reads it. Stop Live also wipes the visible lines (FileUpload.tsx:863-873).

What Clear means

  • Clear empties the live window only. Recording, the WebSocket and action items keep running.
  • Live text is never saved, so the session folder, transcript.md and the post-recording transcript are unaffected. The full transcript is still built from the audio after End Recording.
  • Action items are not cleared: they are stored per recording and may have been edited by hand.
  • Copy & Clear copies first and clears only if the copy succeeded. It never asks for confirmation, because the text is already on the clipboard.
