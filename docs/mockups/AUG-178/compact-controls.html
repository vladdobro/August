Decisions to agree

  • D1 → Praxis from compact expands August and opens the existing Send to Praxis modal with the chosen item(s) preselected (project choice needs the full window). Alternative rejected for now: one-click send to the last used project.
  • D2 Switch is in place and within the variant only (Square ↔ Strip, Coin ↔ Caption); it is a session override, Settings stay unchanged; the transcript widget is unavailable while Live text is off.
  • D3 Start Live Text works both after Stop Live Text and in a recording started without Live; it uses the saved live engine; the window starts empty.
  • D4 Opacity changes the Ghost Caption background only; text stays 100 %. Size and opacity persist (new prefs).
  • D5 Dock Square Pause appears only while Live is on — Default recordings still have no pause (decision 2026-10-29: pause = live-text pause only).
  • D6 Not chosen: Copy in Dock Square / Ghost Coin; participants fields in compact.
