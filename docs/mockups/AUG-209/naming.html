Naming a transcription

Pop-up variants P1–P3 offer a name suggested by the language model. T1–T3 and S1–S2 are the inline alternatives. Naming is always optional.

P1 · Pop-up when transcription starts (corner)

Appears on the timer page, does not cover the ring, never takes keyboard focus. The model can only suggest a name once the text exists, so the suggestion arrives near the end.
