Research summary

Audio pipeline today

  • Mic: getUserMedia (client/src/components/FileUpload.tsx:343) → Web Audio graph micSource → recordDest (FileUpload.tsx:380-390, AUG-125) → recordStream → MediaRecorder, 30 s timeslice (449-451, 606). Device loss re-attaches a new micSource into the same recordDest (456-480).
  • System track, two paths: server capture (FileUpload.tsx:544-550 → server/src/services/systemCapture.ts: Windows WASAPI loopback helper / Stereo Mix / VB-Cable via dshow, macOS audiotee / BlackHole via avfoundation, lines 14-27, 220-223) or the browser picker getDisplayMedia with its own MediaRecorder (FileUpload.tsx:552-594).
  • Level bars: AnalyserNode on recordStream, or the mic+system mix in picker mode (FileUpload.tsx:596-641).
  • Live: liveTranscriptionClient taps recordStream (FileUpload.tsx:646-648; client/src/services/liveTranscriptionClient.ts:266-286), resamples to 16 kHz, ChunkAccumulator 4 s / 1 s overlap (95-120) with an RMS speech gate (24-69). Them = browser tap (241-264) or server tee (attach-capture, AUG-113). Live Pause only stops sending chunks (294-300).
  • Post-recording: mic + system files upload with micStartedAt (FileUpload.tsx:396-446); server/src/routes/sessions.ts:672, 745 computes systemOffsetMs = capture.startedAt − micStartedAt; runDualTranscription (sessions.ts:165) → alignDualSegments (server/src/services/transcriptMerger.ts:210) → mergeDualStream (251). Batch whisper runs with Silero VAD (server/src/services/whisper.ts:440-517, 662).
  • Key fact: on both Windows and macOS the microphone is captured only in the renderer. The server capture only ever produces the system track, so mute is a renderer-only change.

Caveats

  • The OS microphone indicator (macOS orange dot, Windows mic icon) stays on while muted: the device stays open so unmute is instant and the file keeps its length.
  • Mute in August does not mute you in Zoom/Meet/Teams; the tooltip says "Mute in August's recording".
  • If the mic reaches the system track (Stereo Mix with "Listen to this device", a VB-Cable/Voicemeeter route that mixes the mic into output), August's mute cannot remove it from the system track.
  • Mute resets to off at each new recording, so a forgotten mute never silently drops your side of the next call.

Recommendation

Approach A (+ B as fallback), Variant 1 (control in every view + global hotkey Ctrl/Cmd+Alt+M + tray item), red "MIC OFF" indicator in every view.
