Сейчасперекрыто

Видна только первая строка меню. Остальное уходит под панель Action items (z-index: 2).

После AUG-180меню сверху

Меню целиком лежит поверх панели, и до Send to Praxis можно дотянуться.

Почему так. Шапка с backdrop-filter образует свой слой с уровнем 0. У меню z-index: 100, но этот уровень действует только внутри шапки. Панель Action items и плашка исправлений стоят ниже по документу с уровнем 2 и рисуются поверх всей шапки.

Что не меняется. Боковые панели (44–47), кнопки Sessions / Controls (45) и модальные окна (50) по-прежнему выше шапки. Compact-режим не затронут.
