# August - фидбек и фича-реквесты от Родиона

Дата: 1-2 ноября 2026
Источник: обсуждение в личке + демо-звонок

## Feature Request 1 - Расширяемое поле промпта

Поле "Default Prompt" (текстовое поле для инструкций обработки транскрипта) слишком маленькое. Нужно сделать его ресайзабельным - чтобы можно было растянуть вниз и видеть весь текст промпта целиком.

Скриншот: область с `{sessionName}`, `{date}`, `{duration}` и текстовым полем "Process this meeting transcript following these instructions:" - стрелка показывает что нижнюю границу надо расширить.

## Feature Request 2 - Спиннер обработки транскрипта

На экране "EXTERMINATUS INITIATED" (обработка транскрипта, круговой прогресс-бар, REMAINING / Elapsed / Audio) - после того как обработка завершилась (00:00:00, 100%), нет визуальной индикации что процесс ещё идёт. Хочется красивый спиннер/анимацию пока процесс не закончится полностью. Стилистически - в духе остального August.

## Feature Request 3 - Кнопки в live-режиме: Copy & Clear + Clear

Текущий live-режим имеет кнопки `[ COPY ALL ]` и `[ STOP LIVE ]`.

Хотелки:
- Добавить кнопку **[Copy & Clear]** - скопировать транскрипт и очистить окно
- Добавить отдельную кнопку **[Clear]** - просто очистить транскрипт
- В настройках: **Confirmation to clear transcript** - подтверждение перед очисткой (чтобы случайно не потерять текст)
- Кнопка "Stop Live" для меня бесполезна в текущем виде (случайное нажатие страшнее пользы)

---

## Feature Request 4 - Ghost Mode: свободный drag-n-drop

В ghost-режиме (суфлёр/компакт-оверлей поверх экрана):
- Хочется **свободный drag-n-drop по X и Y** с сохранением позиции в конфиг (сейчас перемещение только вверх-вниз)
- Хочу ставить окно в любое место экрана - влево, вправо, куда угодно
- **Не хочу случайно нажать "Stop Meeting"** - эта кнопка слишком доступна в ghost-режиме, нужна защита или убрать её оттуда

---

## Bug Fix 2 - Персистентность проекта в окне "Send to Praxis"

В окне "Send to Praxis" (создание задачи из транскрипта): если я выбираю проект через папку - хочу видеть его сохранённым в дропдауне Project для быстрого выбора в следующий раз. Сейчас каждый раз приходится заново указывать путь.

Контекст обсуждения:
- Влад: "создавать проекты из выбора папки каждый раз - ошибся папкой и 15 проектов на выбор"
- Родион: кнопка [x] для удаления лишних решит проблему, а удобства сразу больше
- Компромисс: как минимум **сохранять последний выбранный путь** в поле внизу

---

## Feature Request 5 - Разделение настройки коррекции

Настройка "Online text correction (Groq)" сейчас включает две функциональности:
1. Исправление строк транскрипта в реальном времени
2. Сбор live action items

Эти функции должны быть **разделены на 2 отдельные галки**. Реальный пример: мне нужны исправления текста, но не нужны текущие action items.

Влад подтвердил что возможно текущие галки уже частично это покрывают, но не тестировал отдельно.

---

## Feature Request 6 - Отключение микрофона во время митинга

Сейчас нельзя отключить микрофон в August пока идёт митинг. В офисе фоновый шум записывается и попадает в транскрипт. Нужна кнопка mute/unmute без остановки записи.
